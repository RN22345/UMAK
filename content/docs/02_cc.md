## Basics

### Computer fundamentals
- **IPOS cycle**: **Input → Process → Output → Storage**. **Data** = raw facts and figures; **Information** = processed, meaningful data.
- **Hardware** = the physical parts you can touch; **Software** = programs; **Firmware** = software embedded in hardware (BIOS/UEFI).
- **Supercomputer**: weather forecasting, nuclear simulation, measured in **FLOPS**. Ranked twice a year in the **TOP500** list.
- **Analog** = continuous values (speedometer, thermometer); **Digital** = discrete 0/1; **Hybrid** = both (ICU monitors).

### History
- **Charles Babbage** = "Father of the Computer" (Analytical Engine). **Ada Lovelace** = first programmer.
- **Blaise Pascal**: **Pascaline** (1642), a mechanical adder. **Herman Hollerith**: tabulating machine for the 1890 US census; his company became **IBM**.
- **Colossus** (UK, 1943-44): **code-breaking**. **ENIAC**: first general-purpose electronic digital computer.
- **John von Neumann**: **stored-program concept** (program and data share the same memory).
- **Generations**: 1st **vacuum tubes** · 2nd **transistors** · 3rd **integrated circuits (ICs)** · 4th **microprocessors**.
- **Intel 4004** (1971): first commercially available microprocessor.
- **Moore's Law**: transistors per chip double about every 2 years.
- **Tim Berners-Lee** proposed the **World Wide Web** at CERN. **Ray Tomlinson** introduced the **@** symbol in email (1971).

### Hardware, memory and devices
- **ALU** = the CPU part that does arithmetic and logical operations (CPU = CU + ALU + registers).
- Speed order: **Registers** (fastest) → cache → RAM → disk. **RAM** is **volatile**; **ROM** is non-volatile and stores BIOS/firmware. **SRAM** is faster and is used for **CPU cache**.
- **Bit** = smallest unit; **nibble** = **4 bits**; **byte** = **8 bits**.
- **Input** devices: keyboard, mouse, **scanner**. **Output**: monitor, **printer**. **Both**: **touchscreen**, modem.
- **OMR** reads marked bubbles on exam answer sheets; **MICR** reads bank cheques; **OCR** reads printed text.
- **RJ-11** = telephone line connector; RJ-45 = Ethernet.

### Software
- **System software**: operating system (Windows, **Linux**), **device drivers**, firmware, utilities. **Application software**: Word, Excel, browsers, games.
- **Compiler** = translates the **whole** source into an executable before running. **Interpreter** = executes **line by line**. **Assembler** = assembly to machine code.
- Language generations: **1GL** machine · **2GL assembly** · **3GL** high-level (C, Java, Python) · **4GL SQL** · 5GL AI/constraint (Prolog).
- Files and formats: Word = **.docx**, Excel = .xlsx, PowerPoint = .pptx.
  - **PNG** = lossless + transparency; **JPEG** = lossy; **GIF** = **256 colors** + animation; **SVG** = **vector**, scales without loss. **MP3** = lossy audio.
- **Excel**: every formula starts with **=**; relative ref `A1`, **absolute ref `$A$1`**.
- Shortcuts: **Ctrl+Z** undo · Ctrl+C copy · Ctrl+V paste · **Ctrl+Shift+Esc** opens Task Manager.

### Number systems
- **Binary** base 2 (0-1) · Octal base 8 · Decimal base 10 · **Hexadecimal** base 16 (**0-9 and A-F**).
- 11111111₂ = **255** (also 0xFF). 1010₂ = 10.
- **ASCII** = **7-bit**, 128 characters (extended ASCII = 8-bit, 256).

### Information systems and internet
- **TPS** = day-to-day **operational** transactions (payroll, order processing). **MIS** = **periodic performance reports** for middle managers (sales, inventory, budgeting). **DSS** = what-if analysis for senior managers. **EIS/ESS** = strategic, long-term decisions for **executives**.
- **Internet** = a **global network of networks**. **Intranet** = private network inside an organization. **Extranet** = shared with partners.
- **Cloud models**: **IaaS** = raw infrastructure/virtual machines (AWS EC2) · **PaaS** = platform for developers (Heroku, Google App Engine) · **SaaS** = ready-made apps (**Gmail, Office 365**).

## What is a computer?
- An electronic device that **accepts data (input) → processes → stores → outputs information** (IPOS cycle: *Input, Process, Output, Storage*).
- **Data** = raw facts/figures; **Information** = processed, meaningful data; **Knowledge** = information + experience/context.
- Characteristics: speed, accuracy, diligence (no fatigue), versatility, storage capacity, automation.
- **Hardware** (physical) · **Software** (programs) · **Peopleware / liveware** (users) · **Firmware** (software embedded in hardware, e.g., BIOS/UEFI) · **Data/Procedures**.

### Electronic era
- **Z3** (Konrad Zuse, 1941) – first working programmable, fully automatic digital computer.
- **Atanasoff–Berry Computer (ABC)** – first electronic digital computer (no general programmability).
- **Colossus** (UK, 1943–44) – code-breaking.

- **ENIAC** (J. Presper Eckert & John Mauchly, 1945–46) – first general-purpose electronic digital computer.
- **von Neumann architecture** (1945, John von Neumann): stored-program concept (program and data share memory).
- **EDVAC, EDSAC (1949), Manchester Baby (1948)** – first stored-program machines.
- **UNIVAC I** (1951) – first commercially produced computer in the US.

- **Transistor**: Bell Labs, 1947 (Bardeen, Brattain, Shockley).

## Types of computers
- **By size/power:** *Supercomputer* (weather, nuclear sim; measured in FLOPS) > *Mainframe* (banks, airlines; high I/O & reliability) > *Minicomputer* > *Microcomputer* (PC, laptop, tablet, smartphone).
- **By data handled:** *Analog* (continuous, e.g., speedometer, thermometer) · *Digital* (discrete 0/1) · *Hybrid* (ICU monitors, gas pump).
- **By purpose:** general-purpose vs special-purpose (embedded).
- **Embedded systems**: dedicated computer inside a device (microwave, ATM, car ECU).
- **Fastest supercomputers** are ranked in the **TOP500** list (twice a year, June & November). *El Capitan* (US, LLNL) topped the list from Nov 2024 through 2025 (check latest if asked).

## Hardware

### 4.1 CPU & internals
- **CPU** = Control Unit (CU) + Arithmetic Logic Unit (ALU) + Registers. Speed measured in **GHz**; has **cores**, **threads**, **cache (L1/L2/L3)**.
- **Machine cycle:** Fetch → Decode → Execute → Store (see `08_Computer_Architecture.md`).
- **Motherboard**: main circuit board; **chipset**, **BIOS/UEFI**, **CMOS battery**, **expansion slots (PCIe)**, **RAM slots (DIMM)**, **SATA/M.2**.
- **GPU**: graphics/parallel processing (now the engine of AI training). **APU** (AMD) = CPU+GPU. **SoC** = system on chip (phones, Apple Silicon). **NPU** = neural processing unit.
- **PSU** converts AC to DC. **Cooling**: heatsink, fan, liquid, thermal paste.

### 4.2 Memory & storage hierarchy (fast/small → slow/large)
Registers → Cache → RAM → SSD/HDD → Optical/Tape/Cloud.
| Type | Volatile? | Notes |
|---|---|---|
| RAM (DRAM) | Yes | working memory; DDR4/DDR5; SRAM is faster (cache) |
| ROM / PROM / EPROM / EEPROM / Flash | No | firmware, BIOS |
| HDD | No | spinning platters, magnetic |
| SSD | No | NAND flash; SATA vs **NVMe (PCIe)**; form factors 2.5", **M.2** |
| Optical | No | CD ≈ 700 MB · DVD 4.7 GB (single-layer) · Blu-ray 25 GB (single-layer) |
| Tape | No | archival/backup |

**Units:** 1 byte = 8 bits · 1 nibble = 4 bits · KB = 1,024 B · MB · GB · TB · PB · EB · ZB · YB (powers of 1,024 in classical teaching; SI "kilobyte=1000" vs "kibibyte (KiB)=1024").
**Speeds:** Hz, MHz, GHz (clock); bps/kbps/Mbps/Gbps (network); MB/s (disk).

### 4.3 Input / Output devices
- Input: keyboard, mouse, scanner, webcam, microphone, touchscreen, barcode/QR reader, **OMR** (optical mark recognition – exam sheets), **OCR** (text recognition), **MICR** (banks – cheques), biometric scanner, stylus, joystick.
- Output: monitor (LCD/LED/OLED), printer (inkjet, laser, dot-matrix, thermal, 3D), speaker, projector, plotter.
- I/O both: touchscreen, modem, network card, external drive.
- **Resolution**: pixels (e.g., 1920×1080 = Full HD; 3840×2160 = 4K UHD). **DPI** printer resolution; **PPI** screen; **refresh rate** in Hz.

### 4.4 Ports & connectors
USB (A, B, **C**), USB 2.0 (480 Mbps), 3.0/3.1 Gen1 (5 Gbps), 3.2 (10/20 Gbps), **USB4 (40 Gbps)** · HDMI · DisplayPort · VGA (analog) · DVI · **Thunderbolt** · RJ-45 (Ethernet) · RJ-11 (phone) · 3.5 mm audio jack · PS/2 (legacy keyboard/mouse) · SATA · eSATA · Bluetooth (wireless, short range) · NFC (~4 cm).

## Number systems & data representation (quick)
| System | Base | Digits |
|---|---|---|
| Binary | 2 | 0–1 |
| Octal | 8 | 0–7 |
| Decimal | 10 | 0–9 |
| Hexadecimal | 16 | 0–9, A–F (A=10 … F=15) |

- Binary → decimal: 1011₂ = 8+0+2+1 = **11**. 11111111₂ = **255**. 2⁸ = 256, 2¹⁰ = 1024.
- Decimal → binary: repeated division by 2, read remainders bottom-up. 25 = **11001**₂.
- Hex ↔ binary: group by 4 bits. **0xFF = 1111 1111 = 255**; 0x1A = 26; 0x10 = 16.
- Binary addition: 1+1 = 10 (carry). Two's complement: invert bits + 1 (signed integers). Range of n-bit signed = −2ⁿ⁻¹ … 2ⁿ⁻¹−1 (8-bit: −128…127).
- **ASCII**: 7-bit, 128 chars ('A' = 65, 'a' = 97, '0' = 48, space = 32). Extended ASCII 8-bit = 256. **Unicode**: universal; **UTF-8** (variable 1–4 bytes, backward compatible with ASCII), UTF-16, UTF-32. **EBCDIC** = IBM mainframe code.
- **BCD** = binary coded decimal. **Gray code**: only one bit changes between successive values.
- Boolean/gate logic → `03_Logic_Formulation.md`.

## Information systems
- Components: **Hardware, Software, Database/Data, Network, People, Procedures** (also "Processes").
- **Types along the organization pyramid:**
  - **TPS** (Transaction Processing System) – operational level: payroll, order processing, reservations, stock control.
  - **MIS** (Management Information System) – middle managers: periodic reports, performance (sales, inventory, budgeting).
  - **DSS** (Decision Support System) – senior managers: "what-if" projection, knowledge-based.
  - **EIS/ESS** (Executive Information System) – strategic level, executives, long-term goals.
  - Others: ECS (Enterprise Collaboration), **PCS** (Process Control), **EDMS** (Electronic Document Management), expert systems (MYCIN, DENDRAL, R1/XCON), ERP, CRM, SCM, **KMS**.
- **Business processes** and IT projects: sources of projects = **Problem, Opportunity, Directive**.

## Internet & emerging tech
- **Internet** = global network of networks. **Web** = service on the Internet (HTTP/HTML). **Intranet** (private org network), **Extranet** (partners).
- **Cloud computing:** IaaS (AWS EC2, Azure VMs), PaaS (Heroku, Google App Engine), SaaS (Gmail, Office 365). Models: public, private, hybrid, community. Key providers: **AWS, Microsoft Azure, Google Cloud**.
- **IoT**, **big data (5 Vs)**, **blockchain** (distributed ledger; Bitcoin 2009 by "Satoshi Nakamoto"; Ethereum = Vitalik Buterin), **AR/VR/MR**, **5G**, **edge computing**, **quantum computing (qubits, superposition, entanglement)**, **digital twins**, **robotic process automation (RPA)**, **3D printing**, **drones**, **low-code/no-code**.
- **Web 1.0** (read-only) → **Web 2.0** (read-write, social) → **Web 3.0** (semantic / decentralized).
- **Social engineering, digital footprint, digital citizenship, netiquette** → see `11_IT_Security.md`.
