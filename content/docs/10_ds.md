## 1. Definitions
- **Data science** = interdisciplinary field using statistics, programming, and domain knowledge to extract insight from data. Term popularized by **DJ Patil & Jeff Hammerbacher** ("sexiest job of the 21st century" – HBR 2012). **Data analytics** = examining data to draw conclusions (more focused/applied). **Business intelligence (BI)** = dashboards/reports on historical data. **Data mining** = discovering patterns in large datasets (KDD step). **Data engineering** = building pipelines/infrastructure.
- **Roles:** data analyst, data scientist, data engineer, ML engineer, BI developer, analytics engineer, data steward, CDO (Chief Data Officer).
- **Types of analytics:**
  | Type | Question | Example |
  |---|---|---|
  | **Descriptive** | What happened? | monthly sales report |
  | **Diagnostic** | Why did it happen? | drill-down on drop in sales |
  | **Predictive** | What will happen? | forecast demand, churn model |
  | **Prescriptive** | What should we do? | optimization, recommendations |
  | (Cognitive/Augmented) | AI-assisted | |
- **DIKW pyramid:** Data → Information → Knowledge → Wisdom.

## 2. Data lifecycle & process models
- **CRISP-DM:** **Business understanding → Data understanding → Data preparation → Modeling → Evaluation → Deployment** (cyclic). **KDD:** Selection → Preprocessing → Transformation → Data mining → Interpretation. **OSEMN:** Obtain, Scrub, Explore, Model, iNterpret. **Data lifecycle:** generation → collection → storage → processing → analysis → visualization → sharing → archive/deletion.
- **Data sources:** databases, APIs, web scraping (BeautifulSoup, Scrapy), logs, sensors/IoT, surveys, social media, open data (data.gov, **PSA/PhilGEPS/Open Data PH**), Kaggle.

## 3. Types of data
- **Structured** (tables/SQL), **semi-structured** (JSON, XML, logs, NoSQL), **unstructured** (text, images, audio, video; ~80 % of enterprise data).
- **Qualitative (categorical)**: *nominal* (no order: gender, color) · *ordinal* (ordered: rating 1–5, education level). **Quantitative (numeric)**: *discrete* (counts) · *continuous* (measurements). Scales **NOIR**: **N**ominal, **O**rdinal, **I**nterval (no true zero: °C, dates), **R**atio (true zero: weight, income, Kelvin).
- **Big data 5 Vs:** **Volume, Velocity, Variety, Veracity, Value** (3 Vs by Doug Laney: volume, velocity, variety). Tools: **Hadoop** (HDFS storage, MapReduce, YARN), **Apache Spark**, **Kafka** (streaming), **Flink**, Hive, HBase, **Airflow** (orchestration), dbt. Units beyond TB: PB, EB, ZB.
- **Data formats:** CSV, TSV, **JSON**, XML, YAML, Excel, **Parquet / ORC / Avro** (columnar/binary for big data), SQL dump, HDF5.

## 4. Data preparation (wrangling/cleaning) – ~60–80 % of the work
- **Issues:** missing values, duplicates, inconsistent formats, outliers, wrong types, noise, bias.
- **Missing data:** drop rows/cols, **impute** (mean/median/mode, forward fill, KNN, model-based). Types: MCAR, MAR, MNAR.
- **Outliers:** detect with **IQR rule** (below Q1 − 1.5·IQR or above Q3 + 1.5·IQR), **z-score** (|z| > 3), box plot; handle: remove, cap (winsorize), transform.
- **Scaling:** **Min–max normalization** x′ = (x − min)/(max − min) → 0–1; **Standardization (z-score)** z = (x − μ)/σ → mean 0, SD 1.
- **Encoding categorical:** label encoding, **one-hot encoding**, ordinal encoding, target encoding. **Feature engineering:** creating/transforming features, binning, polynomial, date parts, text → TF-IDF/embeddings. **Feature selection:** filter, wrapper, embedded (Lasso). **Dimensionality reduction:** **PCA**, t-SNE, UMAP. **Curse of dimensionality.**
- **Sampling:** simple random, **stratified**, systematic, cluster, convenience; **train/validation/test split** (e.g., 70/15/15 or 80/20); **data leakage** (test info leaking into training) is a pitfall. **Class imbalance:** SMOTE, over/under-sampling, class weights.
- **Data quality dimensions:** accuracy, completeness, consistency, timeliness, validity, uniqueness. **Data governance**, lineage, catalog, MDM.

## 5. Statistics essentials
- **Population vs sample**; **parameter vs statistic**.
- **Central tendency:** mean (sensitive to outliers), **median** (middle value; robust), **mode** (most frequent). Dataset {2, 3, 3, 5, 7, 9, 100}: mean = 129/7 ≈ 18.4; median = 5; mode = 3.
- **Dispersion:** range, **variance** (σ²), **standard deviation** (σ = √variance), **IQR** = Q3 − Q1, MAD; **coefficient of variation**. Sample SD uses **n − 1** (Bessel's correction).
- **Shape:** skewness (right/positive: mean > median > mode), kurtosis. **Percentiles/quartiles**, five-number summary (min, Q1, median, Q3, max).
- **Correlation:** Pearson r ∈ [−1, 1] (+1 perfect positive, 0 none, −1 perfect negative); **Spearman** (rank); **correlation ≠ causation**; **covariance**; **R²** (coefficient of determination).
- **Probability:** P(A∪B) = P(A)+P(B)−P(A∩B); conditional P(A|B) = P(A∩B)/P(B); **Bayes' theorem** P(A|B) = P(B|A)P(A)/P(B); independent events P(A∩B)=P(A)P(B); expected value.
- **Distributions:** **Normal (Gaussian; bell curve)** — **68–95–99.7 rule** (±1σ, ±2σ, ±3σ); standard normal (μ=0, σ=1); Binomial, Poisson, Uniform, Exponential, t-distribution, chi-square. **Central Limit Theorem**: sample means tend to normal as n grows. **Law of large numbers.**
- **Hypothesis testing:** H₀ (null) vs H₁ (alternative); **p-value** (probability of data at least this extreme if H₀ true); reject H₀ if p < **α** (commonly **0.05**); **Type I error** (false positive; reject true H₀; probability α) vs **Type II error** (false negative; fail to reject false H₀; probability β); **power = 1 − β**. Tests: **t-test**, **z-test**, **chi-square** (categorical), **ANOVA** (3+ means), Mann–Whitney. **Confidence interval** (95 % CI). **A/B testing**. **Simpson's paradox**.
- **Regression:** linear y = β₀ + β₁x + ε (least squares); multiple; logistic (classification); assumptions (linearity, independence, homoscedasticity, normal residuals); **multicollinearity**.
- **Time series:** trend, seasonality, cyclic, noise; moving average, exponential smoothing, **ARIMA**, Prophet, LSTM.

## 6. Machine learning fundamentals
- **ML (Arthur Samuel, 1959)** = computers learn from data without being explicitly programmed. **AI ⊃ ML ⊃ Deep Learning ⊃ Generative AI.**
- **Learning types:** **Supervised** (labeled) — *classification* (spam/not spam, discrete) & *regression* (house price, continuous). **Unsupervised** (unlabeled) — *clustering*, *dimensionality reduction*, *association rules* (market basket: Apriori, FP-Growth), anomaly detection. **Semi-supervised**, **Self-supervised** (LLM pretraining), **Reinforcement learning** (agent–environment–reward; AlphaGo, RLHF).
- **Algorithms:** Linear/Logistic Regression · **Decision Tree** · **Random Forest** (bagging ensemble) · **Gradient Boosting** (XGBoost, LightGBM, CatBoost) · **SVM** (maximal margin, kernel) · **k-NN** (lazy learner, distance) · **Naïve Bayes** (Bayes + independence assumption) · **k-Means** (centroids; choose k with elbow/silhouette) · Hierarchical clustering (dendrogram) · **DBSCAN** (density) · PCA · Apriori · Neural networks.
- **Ensembles:** bagging (parallel; reduce variance), boosting (sequential; reduce bias), stacking.
- **Training concepts:** model parameters vs **hyperparameters** (learning rate, depth, k); **loss function** (MSE, MAE, cross-entropy); **gradient descent** (SGD, mini-batch, Adam); **epoch, batch**; **overfitting** (memorizes training data; high variance) vs **underfitting** (high bias); **bias–variance trade-off**; **regularization** (**L1/Lasso**, **L2/Ridge**, dropout, early stopping); **cross-validation (k-fold)**; grid/random search; data augmentation.
- **Evaluation – Classification:** **Confusion matrix** (TP, FP, TN, FN).
  - **Accuracy** = (TP+TN)/(TP+TN+FP+FN)
  - **Precision** = TP/(TP+FP) (of predicted positives, how many right)
  - **Recall / Sensitivity / TPR** = TP/(TP+FN) (of actual positives, how many found)
  - **Specificity** = TN/(TN+FP) · **FPR** = FP/(FP+TN)
  - **F1** = 2·P·R/(P+R) (harmonic mean) · **ROC curve / AUC** (1.0 perfect, 0.5 random)
  - Example: TP=40, FP=10, FN=20, TN=30 → accuracy = 70/100 = 0.70; precision = 40/50 = 0.80; recall = 40/60 ≈ 0.667; F1 = 2(0.8×0.667)/(1.467) ≈ 0.727.
- **Regression metrics:** MAE, MSE, **RMSE** (same units as target), **R²**, MAPE.
- **Libraries:** **scikit-learn**, **TensorFlow** (Google), **PyTorch** (Meta), **Keras**, XGBoost, Hugging Face Transformers, ONNX, MLflow. **MLOps**: versioning, CI/CD for models, monitoring (data/concept drift), feature stores.

## 7. Deep learning & modern AI (links to `13`)
- **Neural network**: layers of neurons (input, hidden, output); weights & biases; **activation functions** (**ReLU**, sigmoid, tanh, **softmax** for multi-class probabilities, GELU); **backpropagation** (Rumelhart, Hinton, Williams 1986); **perceptron** (Frank Rosenblatt, 1958).
- **Architectures:** **CNN** (images; convolution & pooling), **RNN / LSTM / GRU** (sequences), **Transformer** (Google, **"Attention Is All You Need", 2017**; self-attention; base of GPT/BERT/Claude/Gemini), **GAN** (Ian Goodfellow 2014), **Autoencoder/VAE**, **Diffusion models** (Stable Diffusion, DALL·E, Midjourney, Sora), **Graph NN**, **Mixture of Experts (MoE)** — only some experts active per token.
- **LLM concepts:** token, context window, embeddings, parameters, pretraining → fine-tuning → **RLHF**, prompt engineering, **hallucination**, temperature, **RAG** (retrieval-augmented generation with vector DB), agents, tool use, **MCP**, multimodal, reasoning models ("thinking"), quantization, distillation, open-weight vs closed.
- **NLP:** tokenization, stop words, stemming vs lemmatization, n-grams, **TF-IDF**, word2vec/GloVe embeddings, BERT, sentiment analysis, NER, machine translation, summarization, chatbots, speech recognition (Whisper), TTS. **Computer vision:** classification, object detection (YOLO), segmentation, OCR, face recognition, GANs. **Recommender systems:** collaborative vs content-based filtering (Netflix/Spotify/YouTube).
- **Responsible AI:** bias/fairness, transparency, explainability (**XAI**: SHAP, LIME), privacy, accountability, safety/alignment, deepfakes, copyright, EU AI Act (2024). PH: Data Privacy Act; national AI strategy (NAISR); DICT.

## 8. Data visualization & BI
- **Chart choice:**
  | Goal | Chart |
  |---|---|
  | Compare categories | **Bar/column** |
  | Trend over time | **Line** |
  | Part-to-whole | **Pie/donut** (few categories), stacked bar, treemap |
  | Distribution | **Histogram**, box plot (shows median, quartiles, outliers), violin |
  | Relationship | **Scatter**, bubble |
  | Correlation matrix / density | **Heatmap** |
  | Flow / process | Funnel, Sankey, waterfall |
  | Geographic | Choropleth map |
  | Schedule | Gantt |
  | Single KPI | Gauge / big-number card |
- **Principles:** data-ink ratio (**Edward Tufte**), avoid truncated axes & 3D distortion, color accessibility (color-blind safe), clear titles/labels, one message per chart. **Dashboard** = consolidated visual KPI view. **KPI** = key performance indicator (SMART). **Storytelling with data.**
- **Tools:** **Excel** (pivot tables, charts, Power Query), **Power BI** (Microsoft), **Tableau** (Salesforce), Looker/Looker Studio (Google), Qlik, Metabase, Apache Superset, Grafana (time series), Google Sheets. **Python:** **pandas**, **NumPy**, **Matplotlib**, **Seaborn**, **Plotly**, scikit-learn, SciPy, statsmodels; **R** (ggplot2, tidyverse); **Jupyter Notebook**, **Google Colab**, VS Code, SQL; **Julia**; SAS, SPSS, MATLAB.
- **pandas cheats:** `import pandas as pd` · `df = pd.read_csv("f.csv")` · `df.head()` · `df.info()` · `df.describe()` · `df.shape` · `df.isnull().sum()` · `df.dropna()` · `df.fillna(0)` · `df['col'].value_counts()` · `df.groupby('a')['b'].mean()` · `df.merge(df2, on='id')` · `df.sort_values('x')` · `df.loc[]` (label) vs `df.iloc[]` (position) · `pd.concat()`. **NumPy**: `np.array`, `np.mean`, `np.std`, broadcasting.
- **Excel analytics:** Pivot Table (summarize), VLOOKUP/XLOOKUP, SUMIFS/COUNTIFS, IF, charts, Conditional formatting, What-If (Goal Seek, Scenario Manager, Data Table), Solver, Power Pivot, DAX (Power BI).
