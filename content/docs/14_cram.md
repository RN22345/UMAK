## D. Confusable pairs (know the difference!)

| TCP vs UDP | reliable/connected vs fast/connectionless |
| POP3 vs IMAP | download (and often delete) vs sync on server |
| HTTP vs HTTPS | plain vs TLS-encrypted |
| Virus vs Worm vs Trojan | needs host/user vs self-spreads vs disguised |
| Encryption vs Hashing | reversible with key vs one-way |
| Symmetric vs Asymmetric | one shared key vs public/private pair |
| Authentication vs Authorization | who you are vs what you may do |

| IDS vs IPS | detect/alert vs detect/block |

## E. Formula bank
- **Binary→decimal:** Σ bit × 2^position. **Hosts per subnet:** 2^h − 2. **Subnets:** 2^n.
- **CPU time** = IC × CPI × cycle time · **Amdahl** = 1 / ((1−P) + P/S) · **AMAT** = hit + miss rate × penalty.
- **Turnaround** = completion − arrival · **Waiting** = turnaround − burst.
- **Throughput time** = file size ÷ bandwidth (bits!). 
- **Accuracy** = (TP+TN)/all · **Precision** = TP/(TP+FP) · **Recall** = TP/(TP+FN) · **F1** = 2PR/(P+R).
- **z-score** = (x−μ)/σ · **IQR** = Q3−Q1 · **Min-max** = (x−min)/(max−min).
- **Conversion rate** = orders/visitors · **AOV** = revenue/orders · **CTR** = clicks/impressions.
- **Permutation** n!/(n−r)! · **Combination** n!/(r!(n−r)!) · **Sum 1..n** = n(n+1)/2 · **Hanoi** = 2ⁿ−1.
- **Risk** = threat × vulnerability × impact · **ALE** = SLE × ARO.
- **PERT** = (O + 4M + P)/6.

## G. Added from the IAS & Technopreneurship reviewers
- **7 info characteristics:** Availability, Accuracy, Authenticity, Confidentiality, Integrity, Utility, Possession. **12 threat categories** (IP · QoS · espionage · nature · human error · extortion · sabotage · software attacks · HW failure · SW failure · obsolescence · theft).
- **5 risk strategies:** Defense, Transference, Mitigation, Acceptance, Termination. **SLE** = AV × EF · **ALE** = SLE × ARO · **CBA** = ALE(prior) − ALE(post) − ACS.
- **Due care** (do the right thing) vs **due diligence** (keep doing it, prove it works). Ignorance of **policy** can be a defense; ignorance of **law** is not.
- **SETA:** Education = why (long-term) · Training = how · Awareness = what (short-term). **IRP → DRP → BCP**; sites: hot/warm/cold; shared: time-share, service bureau, mutual agreement.
- **Bell-LaPadula** = confidentiality (no read up / no write down) · **Biba** = integrity (no write up / no read down). **Kerberos** = AS + KDC + TGS (symmetric) · **SESAME** = public-key. **RADIUS** = dial-in central auth.
- **Firewall architectures:** single bastion → screened host → **screened subnet (DMZ)** (dominant). **Enticement** legal; **entrapment** not. **DES** 64-bit block / 56-bit key (NIST 1976) → **AES**. **NIACAP:** definition, verification, validation, post-accreditation. **Lewin:** unfreeze → move → refreeze.
- **4 entrepreneurs:** Innovative, Imitating, Fabian, Drone. **Inventors** = technology developers; **Innovators** = technology users. **Innovation types:** Sustaining (routine), Disruptive (Christensen), Breakthrough (iPhone), Basic research.
- **BMC** (Osterwalder) = 9 blocks; **Lean Canvas** = 9 blocks (Problem, Customer Segments, UVP, Solution, Key Activity, Channels, Cost Structure, Revenue Streams, Unfair Advantage). **IP types (5):** copyright, patent, trade secret, trademark, industrial design; **marks (4):** trademark, service, collective, certification. **Investors (6):** angel, public funding, VC, PE, strategic, banks.
- **Numbers:** focus group 8–12 · dots 5 · rating 0–5 · pitch 30 s–2 min · patent fee Php 1,800 / 3,600 · Google 97% ads · Innovator's Dilemma 1997 · DEFCON 1993 · ACM 1947 · PGP 1991 · SET 1997 · FOIA 1966 · CFA Act 1986 · PATRIOT 2001 · SOX 2002.
