## 2. AI protocols & ecosystem (2024–26)
- **MCP – Model Context Protocol** (Anthropic, Nov 2024): open standard letting AI apps connect to tools/data ("USB-C for AI"); now under the **Linux Foundation** (Agentic AI Foundation, Dec 2025) *(verify)*.
- **A2A – Agent2Agent protocol** (Google, Apr 2025) for agent-to-agent communication; also at the Linux Foundation.
- **ACP – Agentic Commerce Protocol** (OpenAI + Stripe), **AP2** (Google Agent Payments Protocol). **AGENTS.md**. **OpenAPI**. **RAG** + vector DBs. **LLM-as-judge**. **Function/tool calling**.
- **AI agent** = LLM + tools + memory + planning loop. **Agentic coding** (Claude Code, Codex CLI, Cursor, GitHub Copilot agent, Gemini CLI). **"Vibe coding"** (term by **Andrej Karpathy**, Feb 2025). **Computer use** agents. **Deep Research** features.
- Benchmarks: **MMLU**, **GPQA**, **SWE-bench**, **ARC-AGI**, **Humanity's Last Exam (HLE)**, **LMArena (Chatbot Arena)**, Terminal-Bench, Artificial Analysis Intelligence Index.
- Hardware/Cloud: **Stargate** (OpenAI–Oracle–SoftBank), **Colossus** (xAI), **TPU** (Google), **Trainium** (AWS), **Maia** (Microsoft), **H100/B200/GB200/Rubin** (Nvidia), **HBM** memory (SK hynix, Samsung, Micron).
