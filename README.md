# UMAK Quiz Bee Reviewer

Study site for the UMAK 14th IT Olympics Quiz Bee (4 Nov 2026): review notes, a multiple-choice bank and typed-answer flashcards. Static site, hosted on GitHub Pages; progress is kept in the browser's localStorage.

## Layout
```
index.html            page shell
css/styles.css        styling
js/app.js             the app (review, quiz, flashcards, progress)
js/data.js            GENERATED by build.py - do not edit by hand
content/manifest.json lesson order + review-doc list
content/lessons/*.json   one file per lesson: mcq[] and cards[]
content/docs/*.md        review documents
build.py              content/ -> js/data.js (with sanity checks)
```

## Editing content
1. Edit a lesson in `content/lessons/<id>.json` or a doc in `content/docs/`.
   - MCQ: `{"q": "...", "a": "correct", "w": ["wrong1", "wrong2", "wrong3"]}`
   - Card: `{"d": "E|A|D", "q": "...", "a": "answer", "alt": ["other accepted answers"]}` (E/A/D = easy/average/difficult)
2. Run `python build.py` (fails loudly on a malformed question).
3. Commit `js/data.js` together with the content change.

To add a lesson: create `content/lessons/<id>.json`, add its id to `lessons` and its doc to `docs` in `content/manifest.json`, rebuild.
